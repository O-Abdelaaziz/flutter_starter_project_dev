Here is the complete implementation for lib/core/di/ using get_it.

This setup provides a central service locator for registering core network clients, secure local storage, repositories, and feature state controllers.

Folder Structure
Plaintext
lib/core/di/
├── injection_container.dart       # Main setup script initializing dependencies
└── di.dart                        # Barrel export file
Step 1: Add Package Dependency
Ensure get_it is declared in your pubspec.yaml:

YAML
dependencies:
  get_it: ^7.6.0

Step 3: Usage in main.dart
To start your application with all dependencies registered, initialize the container inside your entry point:

Dart
import 'package:flutter/material.dart';
import 'core/di/di.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  
  // Initialize dependency injection service locator
  await initDependencyInjection();

  runApp(const MyApp());
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      home: Scaffold(
        body: Center(child: Text('App Running with Service Locator')),
      ),
    );
  }
}
