Here is an overview of the role and structure of each file within the features/authentication/ feature-first module architecture.

1. Domain Layer (domain/)
The pure business logic layer. It defines core business entities and contract interfaces without depending on any external frameworks, packages, or API details.

domain/entities/user.dart
Role: The core business entity representing an authenticated user in the domain layer. Pure Dart with no serialization logic.

Dart
class User {
  final String id;
  final String email;
  final String fullName;
  final String? avatarUrl;

  const User({
    required this.id,
    required this.email,
    required this.fullName,
    this.avatarUrl,
  });
}
domain/repositories/auth_repository.dart
Role: An abstract interface contract defining the authentication operations available to the presentation layer, separating implementation details from business expectations.

Dart
import '../entities/user.dart';

abstract interface class AuthRepository {
  Future<User> login({required String email, required String password});
  Future<User> register({required String fullName, required String email, required String password});
  Future<void> logout();
}

Responsible for retrieving raw data from remote APIs or local persistent storage, parsing network responses into DTO models, and implementing domain repository contracts.

data/models/user_dto.dart
Role: Data Transfer Object (DTO) handling JSON serialization/deserialization. It maps API payloads and extends or converts into the domain User entity.

Dart
import '../../domain/entities/user.dart';

class UserDTO {
  final String id;
  final String email;
  final String name;

  const UserDTO({required this.id, required this.email, required this.name});

  factory UserDTO.fromJson(Map<String, dynamic> json) {
    return UserDTO(
      id: json['id'] as String,
      email: json['email'] as String,
      name: json['full_name'] as String,
    );
  }

  User toDomain() => User(id: id, email: email, fullName: name);
}
data/models/auth_token_model.dart
Role: Data model representing JWT token pairs (access and refresh tokens) received during authentication.

class AuthTokenModel {

data/repositories/auth_repository_impl.dart
Role: Concrete implementation of AuthRepository. Coordinates data flow between remote API data sources and local storage, returning domain entities to callers.

Dart
import '../../domain/entities/user.dart';
import '../../domain/repositories/auth_repository.dart';
import '../datasources/auth_local_data_source.dart';
import '../datasources/auth_remote_data_source.dart';

class AuthRepositoryImpl implements AuthRepository {
  final AuthRemoteDataSource remoteDataSource;
  final AuthLocalDataSource localDataSource;

  AuthRepositoryImpl({required this.remoteDataSource, required this.localDataSource});

  @override
  Future<User> login({required String email, required String password}) async {
    final userDto = await remoteDataSource.login(email, password);
    await localDataSource.saveAuthToken('sample_jwt');
    return userDto.toDomain();
  }

  @override
  Future<User> register({required String fullName, required String email, required String password}) async {
    throw UnimplementedError();
  }

  @override
  Future<void> logout() async {}
}
3. Presentation Layer (presentation/)
The user interface layer. Contains state management controllers, full screens, and feature-private UI widgets.

presentation/controllers/login_controller.dart
Role: Manages UI state, input validation, and business logic execution for the Login Screen (e.g., BLoC, Cubit, ChangeNotifier, or Riverpod controller).

Dart
import 'package:flutter/foundation.dart';
import '../../domain/repositories/auth_repository.dart';

class LoginController extends ChangeNotifier {
  final AuthRepository authRepository;

  LoginController({required this.authRepository});

  bool isLoading = false;
  String? errorMessage;

  Future<void> login(String email, String password) async {
    isLoading = true;
    notifyListeners();

    try {
      await authRepository.login(email: email, password: password);
    } catch (e) {
      errorMessage = e.toString();
    } finally {
      isLoading = false;
      notifyListeners();
    }
  }
}
